# 🎮 KBD Games

**KBD Games** is a fast-paced, keyboard-based mini game platform designed to improve typing speed and reaction time. Built using modern web technologies, this project blends fun with functionality through interactive challenges powered by JavaScript and styled with Tailwind CSS.



---

## 🚀 Features

- 🎯 Multiple game modes (Alphabet Clash, Reaction Timer, Speed Typing, etc.)
- ⌨️ Real-time keyboard input handling
- 🕹️ Score tracking and dynamic feedback
- 📱 Fully responsive design
- 🌙 Light/Dark mode toggle (optional)
- 📊 Performance metrics per session (optional)

---

## 🛠️ Tech Stack

- **HTML5** – Structure
- **CSS3 / Tailwind CSS** – Styling and responsive design
- **JavaScript (Vanilla)** – Core game logic
- **DOM Manipulation** – Real-time UI updates
